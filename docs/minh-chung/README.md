# Minh chứng

| Thư mục | Nội dung | Ví dụ tên file |
|---|---|---|
| `api/` | Ảnh Swagger/Postman (request + response JSON) – người làm API nào tự chụp API đó | `products-list.png`, `auth-login.png`, `create-order.png`, `payments.png` |
| `tests/` | Ảnh kết quả chạy test (terminal hoặc CI), gồm test (a), (b), (c) của Task 10 | `test-a.png`, `test-b.png`, `test-c.png` |
| `ci/` | Ảnh CI 1 lần xanh, 1 lần phát hiện lỗi; ảnh CD thành công | `ci-pass.png`, `ci-fail.png`, `cd-pass.png` |
| (thư mục gốc) | Ảnh PWA đã cài trên điện thoại | `pwa.png` |

Tên file: chữ thường, không dấu, nối bằng dấu `-`.

Postman collection để ở [`../postman/`](../postman/).
