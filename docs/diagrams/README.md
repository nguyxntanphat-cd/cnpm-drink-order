# Sơ đồ (Task 1–3 – Assignment 2)

Mỗi sơ đồ nộp **2 file cùng tên**: file nguồn (`.puml` hoặc `.drawio`) **và** ảnh xuất (`.svg` hoặc `.png`) – đề bắt buộc.

| Tên file (không đuôi) | Sơ đồ | Người làm |
|---|---|---|
| `usecase-overview` | Use-case tổng quát toàn hệ thống (Task 1.2) | Lê Thế Hào |
| `usecase-checkout` | Use-case "Đặt và thanh toán đơn hàng" (Task 1.3) | Lê Thế Hào |
| `activity-checkout` | Activity diagram luồng end-to-end, có swimlane (Task 2.1) | Trần Điền Kha |
| `sequence-checkout` | Sequence: Customer → Next.js UI → NestJS API → Database → Payment Service (Task 2.2) | Trần Vy |
| `class-domain` | Class diagram: User, Product, Order, OrderItem, Payment, Promotion, LoyaltyTransaction (Task 2.3) | Nghiêm Hân |
| `deployment` | Deployment diagram môi trường production thật (Task 3.2) | Cao Thanh Tuyền |

Ví dụ: `sequence-checkout.puml` + `sequence-checkout.svg`.
Tên file: chữ thường, không dấu, nối bằng dấu `-`.
