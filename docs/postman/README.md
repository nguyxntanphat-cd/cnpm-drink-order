# Postman collection

| File | Nội dung |
|---|---|
| `BrewLite.postman_collection.json` | Toàn bộ API của BrewLite để cả nhóm import vào Postman (issue #34) |

Cách xuất: Postman → chọn collection → **⋯ → Export** → Collection v2.1 → lưu đúng tên file trên.
Biến môi trường gợi ý: `baseUrl = http://localhost:3001`, `token` = JWT lấy từ `POST /auth/login`.
